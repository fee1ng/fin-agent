# 06: 记录组合与订阅写操作的执行身份

**What to build:** 记录组合与订阅写操作的执行身份，使用户能通过一次真实提问及公开查询验证这条端到端路径。

**Blocked by:** 05 — 通过 Harness 查询行情、新闻和回测

**Status:** ready-for-agent

- [ ] 组合、预警、新闻订阅写工具保持现有输入输出语义。
- [ ] 开始事实持久化后才执行，结果落盘后才返回成功；记录 run_id/execution_id。
- [ ] 可提供幂等键的业务使用幂等键，禁止不确定情况下自动重试写操作。
- [ ] 创建的预警/订阅保留来源运行，后续后台触发按任务身份关联，避免冒充原工具执行。

验证边界：应用提问入口 → 真实 Harness 与本地工具桥 → 持久化记录 → 用户可见结果或轨迹查询。仅使用隔离测试配置与数据；完成本任务不等于已通过最终发布门禁。
