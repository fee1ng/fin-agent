**What to build:** 让一次含敏感信息的提问安全地被记录，使用户能通过一次真实提问及公开查询验证这条端到端路径。

**Blocked by:** 03 — 按提问关联模型尝试与逐工具事件

**Status:** ready-for-agent

- [ ] 写入任何原生记录前过滤配置秘密与敏感字段，覆盖输入、输出、异常及 SDK stderr。
- [ ] 使用假密钥完成一次成功与失败提问，扫描原生日志和查询结果不存在原文。

验证边界：应用提问入口 → 真实 Harness 与本地工具桥 → 持久化记录 → 用户可见结果或轨迹查询。仅使用隔离测试配置与数据；完成本任务不等于已通过最终发布门禁。
