# 03: 按提问关联模型尝试与逐工具事件

**What to build:** 按提问关联模型尝试与逐工具事件，使用户能通过一次真实提问及公开查询验证这条端到端路径。

**Blocked by:** 02 — 真实 Harness 完成一次可持久化的只读工具提问

**Status:** ready-for-agent

- [ ] 接收时持久化 input_id/run_id 和会话映射；用户立即得到运行编号。
- [ ] 每个模型尝试、工具执行保留原生 ID、父子关系、UTC 时间、耗时、错误、用量和版本快照。
- [ ] 同会话排队、跨会话隔离、重复 input_id 去重；不按 idle 或通知时间窗口猜边界。
- [ ] 两次同名工具调用及无工具回答均可按运行编号查询，未提供的字段标记 unavailable。

验证边界：应用提问入口 → 真实 Harness 与本地工具桥 → 持久化记录 → 用户可见结果或轨迹查询。仅使用隔离测试配置与数据；完成本任务不等于已通过最终发布门禁。
