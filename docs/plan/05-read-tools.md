# 05: 通过 Harness 查询行情、新闻和回测

**What to build:** 通过 Harness 查询行情、新闻和回测，使用户能通过一次真实提问及公开查询验证这条端到端路径。

**Blocked by:** 04 — 让一次含敏感信息的提问安全地被记录

**Status:** ready-for-agent

- [ ] 项目只读工具逐个注册，保留业务名和 MCP 名映射，提示词与可用 schema 一致。
- [ ] 复用 AkShare/Tushare provider、技术指标和新版回测，不重复业务实现。
- [ ] 串行执行工具；区分业务错误字符串、协议错误、网络错误和成功结果。
- [ ] 真实 Harness/MCP 测试覆盖行情、新闻、技术指标和回测，回答与轨迹可查。

验证边界：应用提问入口 → 真实 Harness 与本地工具桥 → 持久化记录 → 用户可见结果或轨迹查询。仅使用隔离测试配置与数据；完成本任务不等于已通过最终发布门禁。
