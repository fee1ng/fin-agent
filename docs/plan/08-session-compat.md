# 08: 继续与清空会话时保留历史回溯

**What to build:** 继续与清空会话时保留历史回溯，使用户能通过一次真实提问及公开查询验证这条端到端路径。

**Blocked by:** 04 — 让一次含敏感信息的提问安全地被记录

**Status:** ready-for-agent

- [ ] save 确认原生持久化、load 恢复原会话、clear 创建新上下文而保留旧记录。
- [ ] 旧会话只读展示，继续时显式 imported_context 导入新会话，不伪造历史工具事件。
- [ ] 保留 Session Store 元信息，新模型历史只由原生日志派生。
- [ ] 会话迁移、正常退出和中断后的使用行为通过外部接口测试。

验证边界：应用提问入口 → 真实 Harness 与本地工具桥 → 持久化记录 → 用户可见结果或轨迹查询。仅使用隔离测试配置与数据；完成本任务不等于已通过最终发布门禁。
